# Unknown terms

A name you do not recognize is more likely new than wrong.
Never answer from the closest thing you do know.

Search the name itself, not the familiar one it resembles.
For example, `gemini-3.8-flash` is unknown and `gemini 3` is known —
search `gemini-3.8-flash`. Swapping in the familiar name makes the search
confirm the old answer instead of finding the new one.

Found → use it.
Not found → say so and ask. Do not fill the gap with a guess.

A term that looks project-specific → search the repository first.
Anything else → `web-research.md`.
