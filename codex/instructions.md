# Web research

## Find

- Which page to read → built-in web search

## Fetch

- Only whether a page says something → built-in web browsing
- The page content itself → agent-browser (follow `--help`)

# Command restrictions

Do not run the commands forbidden by the dotfiles command rules, including
through alternate shell syntax. Do not force-push, including when `--force`,
`--force-with-lease`, or `-f` appears after a remote or branch argument.
