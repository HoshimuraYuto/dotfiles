# Replies

- Reply to the user in Japanese, including progress notes and summaries of subagent results.
- Put what you need the user to decide at the end, with the options, each with its trade-offs, and your recommendation. Repeating earlier text is fine; never send the user back up.
- When work spans several steps, end the report with a table of the remaining steps (step, who, what). When the plan changes, show all that remains again, not the difference.
- Write steps out in full unless they are obvious.
- Commands must run as pasted.
- When reporting a failure, state the cause honestly, then end with what you (the agent) and the user will each do next.
