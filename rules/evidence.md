# Evidence and verification

- Treat a claim as settled only when an observation supports it.
- In replies, notes and documents alike, keep facts (what you observed) apart from inferences.

## Finding a cause

Work like a controlled experiment.

- Change one condition at a time, and compare with a case that works.
- Before reading a result as evidence, check that its preconditions held.
- Do not hold on to the first hypothesis. After two misses, question the premises and how you are forming hypotheses.

## Reproducibility

The same steps must give the same result.

- Start a check from a clean state, not on top of earlier runs.
- Record the steps and conditions so anyone gets the same result every time (e.g. for research, the queries and sources; for settings, the values changed; for development, code or scripts instead of manual steps).
- Keep changes reversible (e.g. note the state before changing it, keep it in git).
